# Contributing

Thanks for helping keep this list accurate and comprehensive. Suggestions and corrections are welcome, whether you are adding a new tool, fixing a broken link, updating a description, or removing a product that has shut down.

## What belongs here

A tool qualifies if it meets all of these:

- It is a real, publicly available product that anyone can sign up for or use today.
- It is an AI-powered website builder. AI must generate or substantially assist building the site (for example, generating layout, copy, structure, or code from a prompt). Plain template editors with no AI generation do not qualify.
- It has a working official URL.

A tool does not belong if it is shut down, in a closed private beta with no public access, an affiliate or reseller landing page rather than the product itself, or duplicated under a different name already on the list.

## Entry format

Add one bullet, in this exact format:

```
- [Name](https://official-url) — One neutral, factual sentence describing what it does.
```

Rules:

- Use the official product name and the canonical official URL (follow redirects to the final destination).
- Use one sentence. Start with a capital letter, end with a period.
- Keep it neutral and factual. No marketing language, no superlatives ("best", "easiest", "powerful"), no exclamation marks.
- Separate the link and the description with an en dash (`—`) or a hyphen (`-`). Do not use a triple-hyphen sequence.
- Do not add affiliate links, tracking parameters, or UTM tags to the URL.

## Where to add it

1. Pick the section that best fits the tool: Prompt-to-Website / AI Site Generators, AI Builders for Developers (Code Output), Design-to-Code / Component Generators, E-commerce Site Builders, Landing Page Builders, or Platform and CMS AI Builder Features.
2. Insert the entry in alphabetical order within that section.
3. Make sure the same tool is not already listed (no duplicate links or names).

## How to open a pull request

1. Fork this repository.
2. Edit `README.md` and add or update your entry.
3. Commit your change with a clear message, for example `Add Example Builder to Prompt-to-Website section`.
4. Push to your fork and open a pull request against the `main` branch.
5. Fill out the [pull request template](.github/PULL_REQUEST_TEMPLATE.md) checklist.

Keep each pull request focused: one tool or one fix per pull request makes review faster. Thank you for contributing.
